Plugin lab

Custom directives can plug into state, events and toast flows.

This page registers a tiny plugin with two directives. One autofocuses the first field. The other emits a typed event, stores the last action and raises a toast without changing the core runtime.

Plugin source

Latch.plugin((app) => {
  app.directive("focus", ({ el, value }) => {
    if (value === "immediate") {
      queueMicrotask(() => el.focus());
    }
  });

  app.directive("command", ({ el, value, app }) => {
    el.addEventListener("click", () => {
      app.store("plugin:lastAction", value);
      app.toast(`Plugin command: ${value}`, { type: "info" });
      app.emit("plugin:command", { value });
    });
  });
});
