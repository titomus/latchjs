Latch.js / Distribution

Du JavaScript. Aucun npm.

Téléchargez la bibliothèque prête à utiliser, copiez le fichier dans votre application et chargez-le avec une simple balise script. Les bundles sont reconstruits et publiés automatiquement à chaque mise à jour de main réussie.

Installation en quelques secondes

Placez latch.min.js dans votre répertoire public/assets/, puis collez ce code juste avant la fermeture de </body>.

<script src="/assets/latch.min.js"></script>
<script>Latch.start();</script>

Pour une application en production, préférez le fichier téléchargé et hébergé chez vous. Un lien « latest » peut changer lors de chaque nouvelle publication du projet.
