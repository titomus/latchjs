Reactive collections

Interactive task list with keyed DOM reuse

Add, check, reorder and remove tasks. Latch preserves DOM identity by `lt-key` without a virtual DOM.

03 / Native UI

Common interface patterns, ready to use

Dropdowns, tabs, accordions, modals, drawers and toasts with keyboard support.

Tabs & dropdown

Composed with HTML attributes instead of custom JS controllers.

Simple to compose

Declare a tab group, then pair tab names with panels. Latch handles selection and visibility.

<div lt-tabs="first">
  <button lt-tab="first">First</button>
  <section lt-panel="first">…</section>
</div>
Keyboard-driven UI

Tab and dropdown primitives include ARIA attributes and keyboard navigation. Accessibility still needs testing in your application.

Accordion & overlays

Open, close, confirm or request remote HTML from a tiny runtime.

No. Latch enhances server-rendered HTML with small local state and progressive interactions.
Any server capable of rendering HTML fragments or JSON, including PHP, WordPress, Laravel, Symfony, FlightPHP or Node.
Latch is still in development. Review the security and CSP guidance before production adoption.
