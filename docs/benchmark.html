Experiment details

  • ✓ Independent same-origin iframe for each runtime
  • ✓ 3 warm-up iterations (reactivity), 2 for swaps
  • ✓ Same DOM workload and equal observation point
  • ✓ Median and P95 with raw samples downloadable
  • ✓ Pinned library releases and test fixture
  • ◌ No cross-device or universal victory claim
How to interpret this: A lower median on your machine means that implementation was faster in this narrow workload, not that the entire library is faster. HTMX doesn't manage local reactive state, and Alpine is not primarily a server fragment request engine, so they are compared against Latch on the responsibilities they actually cover. Repeat the run and test your own application before drawing conclusions.
